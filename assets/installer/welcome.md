PartyUp
=======

PartyUp 是一个自托管的、以频道为单位的桌面文字 / 语音 / 屏幕共享软件，
面向 2–12 人的固定小圈子。本安装包是 Windows x64 客户端，已自带 .NET 运行时，
不需要另外安装 .NET。

许可证：GPL-3.0（完整文本随安装目录的 LICENSE.txt 一起分发）。

关于 Windows SmartScreen（请务必阅读）
---------------------------------------
本安装包**没有代码签名证书**（个人项目，不做签名）。从网上下载后首次运行时，
Windows 可能弹出"Windows 已保护你的电脑"（SmartScreen）：

  1. 点「更多信息」；
  2. 点「仍要运行」。

这是未签名程序的正常提示，不是病毒警告。安装包与程序本身都是本仓库脚本
（scripts/package.ps1）从源码构建出来的，你可以自行核对 SHA256 或重新构建。

安装位置
--------
本 MSI 在安装时让你选择安装范围：

  * 仅为我安装（per-user）：装到 %LOCALAPPDATA%\io.partyup.client，**不需要管理员权限**；
  * 为所有用户安装（per-machine）：装到 Program Files，需要管理员权限。

安装完成后会创建桌面与开始菜单快捷方式。

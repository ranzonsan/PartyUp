# AUD02 独立本端输入电平测试合同

状态：2026-11-07 用户已确认先做输入电平测试的 Start／Stop／Status interface 与 fake PCM 验证。生产 monitor、同 ADM observer adapter 与托管 optional 封装已实现，Lead 独立 Linux/MSVC 合成门禁通过；当前候选 v2.18 为 43 导出/caps 0xff。真实采集、硬件/语音交接运行矩阵、旧 DLL 实机兼容与正式 UI 接线未验，PTT 未实现。

## Module 与批准的 seam

输入监测 Module 的 interface 是显式启动、幂等停止、查询状态。生产 adapter 复用同一块 ADM 与官方 observer；测试 adapter 注入合成 PCM，不建另一套音频栈。

- 不加入语音区、不建 PeerConnection、不添加发送音轨、不发送媒体或信令，不改变屏幕发布与接收会话。
- 不改 UI、AXAML、ViewModels；正式 UI 接线与真实麦克风/扬声器验收另列，不能用本批 fake 结果关闭。
- 不临时覆盖 AudioState 已注册的 AudioTransport。使用 SDK 的成熟 observer wrapper，而不是手工复制音频 transport。
- 原 voice_level 的 voice-joined/来源/RMS 语义与布局不变；独立监测不得假装已加入语音，也不得把未测量的零值当有效静音。

## 先完成无硬件预检

官方 [observer interface](<../../third_party/libwebrtc/include/modules/audio_device/include/audio_device_data_observer.h#L25-L47>) 已存在；Lead 已用成熟 nm 确认 release 静态库有定义符号，但这不是实际链接/运行证据。

第一条验证仅链接真实 SDK wrapper，使用 fake ADM 与合成 PCM，观察 observer 与原 transport 的转发。不调用平台 ADM 工厂，不接触真实录音/播放设备、不创建 PC。若链接或行为失败，先调查，不编造缺依赖替代实现，也不通过真实开麦来绕过。

生产 monitor 接线前须获得该预检结果。预检通过仅证明 fake callback/SDK linkage，不等于 WASAPI 采集路径通过；未完整实现前不设置新 cap 或承诺新 ABI。

## 启停与生命周期

- 默认不采集；只有显式 Start 成功才进入监测。语音正在加入、已加入或不能确认独占输入时拒绝，不抢占通话 ADM。
- 遵守既有静音策略，不自动解除手动静音/系统静音。不能安全测量时明确报不支持/静音/错误，不伪报设备损坏或 valid=true。
- Stop 不依赖输出结构体有效性，必须能独立请求停止；重复停止可安全调用。
- 区分请求状态与实际运行状态。Stop/读回失败时报告故障及实际运行或未知状态，禁止仅清 active 镜像就宣称已停。
- VoiceJoin 前停止 monitor，无法确认停止则拒绝继续入语音；析构时在 ADM Terminate 前清理。退出后不交付旧 PCM 统计。
- 设备切换沿用生产控制器的事务/静音门禁/读回，不绕过既有安全启动。切换中窗口、成功回退、永久故障必须区分；inactive fault 不因轮询自动开采集。

## 电平与状态

- 只报告真实 observer PCM 测量；每帧包含静音 PCM 也计入统计，不能用非零阈值过滤后把静音误报成没有数据。
- 状态能够区分未启用、无新鲜数据、有效静音、有效非零 PCM、故障。过期/停止后的旧峰值不能继续有效。
- peak/RMS/帧数/时间戳含义在实现 interface 中明确，结构体遵守 struct_size 与固定布局；旧 DLL 缺新导出时显示不支持，不模拟电平。
- ABI 只做加法，保留原 40 导出及既有布局/默认行为；v2.18 追加 start/stop/status 三导出与 bit7，当前候选共 43。40 字节 status 结构已由 C++ static_assert 核对，托管字段声明编译通过；未把托管构建当作真实调用/旧 DLL 运行兼容验证。

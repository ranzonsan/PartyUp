# PartyUp 标识 v0.2 · 逐字母手绘任务书

> 本文件是唯一规格来源。每位参与者只做一个字母，文件互不重叠。

## 1. 概念（不可变更）

**「Party」这五个字母，每一个都是一个人。悬浮的圆点是它的脑袋。**

不是"字母旁边加个点"，是**字母本身站着，像一个有姿态的人**：竖的是躯干与腿，横向伸出的笔画是手臂/肩，而头——一颗实心的橙色圆点——悬在它的上方，和身体之间留一道干净的空气。

这个标识最终会这样排版：

```
P a r t y        ← 本步要做的五个字母，站在同一条基线（地面）上
================ ← 基线
 ╭──────────╮
 │  U  p    │    ← 下方是「Up」：一个横向拉长的 U + p，抽象成声波
 ╰──────────╯       （本步不做，但必须为它留出空间，别把字母往下压）
```

含义：五个字母就是五个到场的人；下面那道声波是他们的声音。一个自托管的、几个朋友常驻的小服务器。

## 2. 风格契约

- **粗、稳、干净**：笔画粗细统一（72 / 1024），圆头端点，无衬线，不变形、不做旧、不加纹理/渐变/投影。
- **能站住**：竖向笔画扎实，重心稳，整体是"立着"的，不是"飘着"的。
- **有人的姿态，但不是卡通**：允许一点点不对称（微微侧头、肩线略斜、两腿不完全平行）——这一点点就是"人味"；但**不许**变成表情包、火柴人、简笔画小人，也不许手写体化。
- **断口是设计，不是失误**：头和身体之间必须真的空开（30–44 的间隙），任何地方也不能出现"手抖式"的歪线。
- 目标是：**第一眼读作字母，第二眼读作人。**

## 3. 技术规格（硬性）

| 项 | 值 |
| --- | --- |
| 画布 | `viewBox="0 0 1024 1024"`，背景透明（不要画底色） |
| 基线（地面） | y = 800，字母的落地笔画必须精确落在 800 |
| 大写高度 cap | 500（y = 300 到 800）——用于 P、t |
| x-height | 360（y = 440 到 800）——用于 a、r、y 的主体 |
| 下伸 | y 最多到 1000（只有 y 的尾巴会用到） |
| 横向 | 字母以 x = 512 居中；实际墨迹宽度 320–460 之间 |
| 笔画 | `stroke-width="72"`，`stroke-linecap="round"`，`stroke-linejoin="round"` |
| 身体色 | `#F4F1EA`（bone） |
| 头 | 实心正圆，`r` 在 84–105 之间（优先 92），颜色 `#FF5A2B`（ember），**必须与身体完全分离，间隙 30–44** |
| 头的位置 | 见第 5 节——每个字母的头顶位置不同，这是"不同的人"，不要统一成一个模子 |

建议用 `<path stroke=... fill="none">` 画身体、`<circle>` 画头；用 `<g>` 包一层方便我后面对齐。不要用 `<text>`、不要引外部字体/图片。

## 4. 绝对要避免的失败（上一版就死在这里）

- ❌ **图钉 / 气球**：一根细杆顶上戳一个球，读起来是 pin，不是人。
- ❌ 头太小（≤70）或太大（≥110），或离身体太远（>60）——都会散架。
- ❌ 笔画太细（≤56）——细杆托不住头。
- ❌ 字母像现成字体（Futura / Poppins 那种标准形），那样"人"的意味全丢。
- ❌ 为了像人把字母画歪、歪到读不出字母。

## 5. 每个字母：原作草图里它长什么样（按这个来做）

> **已定稿参考**：`brand/v2/letters/p.svg` 与 `a.svg` 已经被作者接受。做 t / y 时**先看这两个文件**（以及它们的 `.png`），按同样的笔粗（72）、同样的头（圆、`#FF5A2B`、间隙 30–44）、同样的"身体先读作字母"的优先级来做。P 的竖干是**断成两段**的——这是作者明确要求的，别"修好"它。

原作者的手稿是"空格子"式的粗描边，五个字母都带一个脱开的圆/块当脑袋。以下是你这个字母要还原的姿态：

| 字母 | 身体 | 头的位置 |
| --- | --- | --- |
| **P** | 竖干**断成两段**（上段墨迹 300–536、下段 600–800，中间约 28 的空气） | 头是**它的碗**，但**必须是 ember 圆环**（不是实心球）：外径 236 = 上段墨迹长度，环中线 r=82 + 环宽 72 → 外缘 r=118；与竖干留 30。实心球实测会读成「!●」，环才读得出 P |
| **a** | 一个大圆碗坐在基线上（x-height），右侧一根竖干 | 头悬在竖干顶端上方，与竖干脱开——注意别让这个头看起来像"i 的点"或德语变音 |
| **r** | 一根竖干（x-height）+ 一小段向右上的肩 | 头悬在肩的右上方，偏右，像人侧着身子看 |
| **t** | 一根竖干（略高于 x-height）+ 横梁 + 右下的一只脚 | 头在竖干顶端正上方，竖干要短，头要靠近，否则又变图钉 |
| **y** | 两笔形成一个 V（x-height），右笔继续下伸成尾，尾巴到 y≈1000 | 头悬在左笔的顶端上方，略微偏左 |

## 6. 交付物（每人一个字母）

```
brand/v2/letters/<字母>.svg     # 1024×1024，透明底，严格按第 3 节
brand/v2/letters/<字母>.png     # 同上，铺在 #0B0C0E 上，1024×1024，供评审
brand/v2/letters/<字母>.md      # 4–8 行：构造要点（关键坐标/半径/间隙）+ 你这版"人味"具体在哪一笔
```

渲染命令（已装好，别自己写渲染器）：

```bash
cd /home/ranzon/PartyUp
PYTHONPATH=.tools python3 brand/tools/render_svg.py brand/v2/letters/p.svg brand/v2/letters/p.png 1024 '#0B0C0E'
```

**必须自检**：渲染后用 `read_image` 看图，至少改两轮再交付。看图时问自己三句：
1. 缩小到 96px 还读得出这个字母吗？
2. 它像"站着的人"还是"插着球的杆"？
3. 如果这是五个字母里的一员，它和邻居摆一起会不会像同一个家族？

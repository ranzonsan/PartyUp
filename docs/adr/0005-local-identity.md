# 身份属于服务器，不做全局账号与联邦

成员身份由单个 Server 创建与验证：本地账号 + 邀请码入服。没有跨服务器账号、没有联邦、没有互通协议。

_Status_: accepted · 2026-11-01

## 考虑过的方案

- **全局账号（像 Discord / Matrix）**：跨服好友与身份连续，但需要中心化注册、找回、封禁与合规——与"只做自托管"直接冲突。
- **仅昵称、无账号**：最轻，但无法做封禁、管理、历史归属。
- **服务器本地账号 + 邀请码**（采用）。

## 后果

- 同一个人在两个 Server 上是两个身份，昵称可以不同。
- 换服 = 重新注册；不做账号迁移。
- 将来若要做联邦，是重写身份层，而不是加一个配置项。

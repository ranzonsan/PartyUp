PartyUp —— 绿色版（便携版）
============================

解压即用，不写注册表、不装服务。整个文件夹可以放在任意位置（U 盘也行）。

启动
----
双击 PartyUp.Client.exe。

首次运行前请注意 Windows SmartScreen
-------------------------------------
本程序**没有代码签名证书**。从网上下载的 zip 解压后首次双击，
Windows 可能弹出"Windows 已保护你的电脑"：

  1. 点「更多信息」；
  2. 点「仍要运行」。

这是未签名程序的正常提示，不是病毒警告。程序只是本仓库 scripts/package.ps1
从源码构建的客户端，可自行核对 SHA256 或重新构建。

系统要求
--------
- Windows 10 1809+ / Windows 11，x64；
- 无需安装 .NET（已自带 .NET 10 运行时）；
- 语音需要麦克风；屏幕共享走系统图形接口，不需要额外驱动。

首次使用
--------
1. 在登录界面填写服务器地址（例如 http://192.168.1.10:8080）；
2. 第一次加入需要邀请码（服务端首次启动会在控制台打印 INVITE_CODE=...），
   填用户名、密码与邀请码后点「注册」。

文件说明
--------
- PartyUp.Client.exe  主程序；
- partyup_media.dll   媒体核心（语音 / 屏幕共享），必须与主程序同目录；
- README.txt          本说明。

卸载
----
直接删除整个文件夹即可（绿色版不产生系统级残留）。

媒体引擎自检
------------
正常启动时日志里应出现：
  媒体引擎：已就绪（ABI v2，24/24 导出）
若显示「媒体引擎不可用」或导出数不足，说明 partyup_media.dll 缺失 / 版本过旧 /
被杀毒软件隔离。

# 频道只有一层，不分类型

Server 下直接是 Channel；每个 Channel 同时承载文字区、语音区与共享区。没有分类树，没有"文字频道 / 语音频道"的类型区分。

_Status_: accepted · 2026-11-01

## 考虑过的方案

- **Discord 式分类树**：导航更强，但会带出继承式权限模型——复杂度真正来自这里。
- **TeamSpeak 式单类型频道**：每个频道只做一件事，用户要在两个频道之间来回切。
- **单层 + 三区**（采用）：参考规模是单服 ≤50 在线、单频道 2–12 人，分类树的导航收益在这个规模下接近零。

## 后果

- 频道多到几十个时，UI 需要分组展示，但**数据模型不加层级**。
- 权限若将来要分级，是给 Channel 加属性，不引入"分类"这层实体。

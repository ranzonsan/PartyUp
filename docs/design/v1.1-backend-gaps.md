# v1.1 UI 所需服务端／媒体内核缺口台账

建立：2026-11-05。维护要求：整个 UI 开发期间持续补充；模拟界面、编译通过、按钮可点，都不代表服务端或内核能力实现。

## 状态与关闭规则

- **未实现**：已找到缺失契约、返回桩或现有接口明确不支持的代码证据。
- **部分已有**：已有相关字段/事件/底层能力，但不足以承载完整 UI 行为。
- **已有，待接线/验证**：不能错误登记为“从零实现”；仍须真实接入并验收。
- **待核查**：静态路径不足以判定，不写成已复现缺陷。
- 本表基于静态只读核查。关闭条目须附正式实现提交、协议/ABI说明（如涉及）及真实端到端验证结果；原型截图不能关闭条目。
- 不在本文预定未经评审的新 API 路径、函数签名或 ABI 版本。原型仍独立于正式客户端、服务端和媒体内核。
